I don’t just write apps — I build the systems events actually run on: registration engines, face-recognition photo platforms, RFID attendance, kiosk check-in, and projection-mapped installations. CTX is the bold/precise sister to **PurpleHat Events’** warm/celebratory side, and we ship client software in between our own product work.

### `~/now`

- 🎥 **EVCa** — event photo platform on **AWS Rekognition** (face indexing + content moderation), **Cloudflare R2** storage, outbox-pattern uploads, DPDPA-compliant biometrics.
- 🧠 **Atlas** — enterprise event-management OS aiming past Cvent/Eventbrite scope.
- 🤖 **AlphaDesk** — 13-agent options-trading research playground (LLM + algo agents).
- ✨ **Experiential tech** — TouchDesigner, Kinect/depth installs, AR photo walls, RFID.
